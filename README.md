# Lessons · Grades 1–12 learning platform

A trilingual (English · Հայերեն · Русский) web app with complete course outlines for grades 1–12 in
Mathematics, Algebra, Geometry, Physics, Drawing, Armenian, Russian and English, built on both the
Armenian state curriculum and the Russian ФГОС curriculum. It ships with a public site for pupils and an
admin panel for editing, publishing and generating lessons with Claude.

## Stack

- **Next.js 15** (App Router, React 19, TypeScript) · **Tailwind CSS 4** · lucide-react icons
- **SQLite** via libsql (prebuilt for Windows, macOS and Linux, no compiler needed) + **Drizzle ORM** (schema in `src/server/db/schema.ts`, migrations in `drizzle/`)
- **next-intl** for the three UI languages (`messages/{en,hy,ru}.json`, routes prefixed `/en`, `/hy`, `/ru`)
- Lesson bodies are Markdown with GFM tables and KaTeX math
- **@anthropic-ai/sdk** for lesson generation (admin button and bulk script)

## One-click start

Double-click the runner for your system (Node.js 20+ must be installed, from <https://nodejs.org>):

| System | File |
|---|---|
| macOS | `Start.command` (first time: right-click → Open if Gatekeeper asks) |
| Windows | `Start.bat` |
| Linux | `start.sh` (or `./start.sh` in a terminal) |

It installs dependencies, creates `.env.local` (asks for an admin password, or generates one and prints
it), seeds the database, builds the app and starts it at <http://localhost:3000>, then opens your browser.
Later starts skip the steps that are already done, but after an update (`git pull` or a new download)
they reinstall dependencies if `package-lock.json` changed, re-seed the database if the course content
changed (pupils, progress and admin edits are kept) and rebuild the app if the code changed. Options: `node start.mjs --dev` for the development
server, `node start.mjs --rebuild` to force a fresh build, `PORT=4000` to change the port.

## Manual start

```bash
npm install
cp .env.example .env.local     # set ADMIN_PASSWORD and ADMIN_SESSION_SECRET
npm run db:seed                # creates data/lessons.db and loads all courses
npm run dev                    # http://localhost:3000/en  (or /hy, /ru)
```

Admin panel: <http://localhost:3000/admin> (password from `ADMIN_PASSWORD`).

## Student accounts and progress

Pupils create their own account at `/en/signup` (username + password, optional grade; no email). Signed-in
pupils get:

- quiz results saved automatically when they finish a lesson quiz (best and latest score, attempt count);
- a **Mark as done** button on every lesson, and completed ticks on the course outline;
- **My progress** (`/en/progress`, also in the phone tab bar): lessons completed, average score, per-subject
  and per-grade progress bars and recent activity, in all three languages.

Admins see every account under **Users** in the admin panel: progress per course, recent attempts, and
actions to rename, change grade, reset the password, disable or delete an account. Student sessions are
signed with the same `ADMIN_SESSION_SECRET`; passwords are stored as scrypt hashes.

Progress data lives in three tables: `users`, `lesson_progress` (one summary row per user and lesson) and
`attempts` (an append-only log with `kind` = `quiz` today, so exams can record `kind` = `exam` later without
a schema change; see `src/server/progress.ts`).

## Content

| Subject | Grades | Source file |
|---|---|---|
| Mathematics | 1–6 | `src/content/subjects/math.ts` |
| Algebra | 7–12 | `src/content/subjects/algebra.ts` |
| Geometry | 7–12 | `src/content/subjects/geometry.ts` |
| Physics | 7–12 | `src/content/subjects/physics.ts` |
| Drawing & Art | 1–7 | `src/content/subjects/drawing.ts` |
| Armenian | 1–12 | `src/content/subjects/armenian.ts` |
| Russian | 1–12 | `src/content/subjects/russian.ts` |
| English | 2–12 | `src/content/subjects/english.ts` |

Every course has trilingual units, lesson titles and **curriculum notes** that explain how the grade maps
onto the Armenian and Russian programmes (hours per week, when a subject starts, exam years, naming
differences). A sample of lessons carries a full trilingual body, objectives and a quiz; the rest are
outlines shown as "Coming soon" until they are written in the admin panel or generated with Claude.

`npm run db:seed` is idempotent: it upserts everything from `src/content` but never overwrites lessons
that were edited in the admin panel or generated by Claude.

### Tips & tricks

Every course also carries a handful of **tips and tricks that are not part of the standard programme**:
mental-math shortcuts, memory aids, problem-solving habits, language hacks, exam strategy and study habits.
They live in `src/content/tips/<subject>.ts` (one `tip(subject, grade, slug, category, [en, hy, ru], {en, hy, ru})`
per tip), are seeded into the `tips` table, and appear as collapsible cards at the bottom of each course page.
Admins can edit, reorder, unpublish, delete or add tips under **Admin → Tips** or on the course page in the admin
panel; tips edited, reordered or deleted there are kept as they are on the next seed (delete is a soft delete, restorable from the editor). `npm run content:check` validates tips too (course exists,
unique slug, three languages, KaTeX formulas, plain-text titles).

## Generating lessons with Claude

Set `ANTHROPIC_API_KEY` in `.env.local`, then either press **Generate with Claude** on any lesson in the
admin panel, or run the bulk script:

```bash
npm run generate -- --course math-1          # all empty lessons of one course
npm run generate -- --subject physics --grade 7
npm run generate -- --lesson algebra-7-identities --force
npm run generate -- --limit 25               # first 25 empty lessons overall
```

Generated lessons are stored with `source = "claude"` and published automatically by the script; lessons
generated from the admin panel stay in draft until you review and publish them. The model defaults to
`claude-opus-5-5` and can be changed with `CLAUDE_MODEL`.

## Project layout

```
src/app/[locale]/            public site (home, grade, subjects, course, lesson, login, signup, progress)
src/app/admin/               admin panel (login, dashboard, courses, lesson editor, tips, users)
src/app/api/admin/           JSON API used by the admin panel
src/app/api/auth|progress/   student sign-up / login and progress recording
src/components/site|admin|ui UI components (Claymorphism design tokens in src/app/globals.css)
src/content/                 seed content (TypeScript) and helpers; src/content/tips/ holds tips & tricks
src/server/                  database client, queries, admin auth, student auth + progress, Claude generation
scripts/seed.ts              npm run db:seed
scripts/generate.ts          npm run generate
```
